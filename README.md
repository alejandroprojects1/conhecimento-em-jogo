# Conhecimento em Jogo

Coletânea de jogos educativos de verdadeiro ou falso criados por estudantes do 6º ano, no componente de Inclusão Digital.

Em cada jogo, o jogador lê uma afirmação, desliza o cartão para responder se ela é verdadeira ou falsa e recebe na hora o resultado com uma explicação. Os jogos foram pensados para apresentar os conteúdos do 6º ano aos estudantes que chegam a essa etapa.

## Estrutura

- `index.html`: página inicial da coletânea, com os jogos organizados por disciplina.
- `jogos/`: um arquivo HTML por jogo.
- `assets/`: logo e outros arquivos compartilhados.

## Como adicionar um jogo

1. Coloque o arquivo do jogo na pasta `jogos/`.
2. Em `index.html`, acrescente um item na lista `jogos` com título, disciplina, autores, descrição, número de perguntas e o caminho do arquivo.
